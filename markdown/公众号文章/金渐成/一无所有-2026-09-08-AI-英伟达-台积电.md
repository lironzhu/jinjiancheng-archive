# 一无所有

> 来源：https://raw.githubusercontent.com/YWW26/jinjiancheng-articles-public/main/2026/2026-09-08_1603_jinjiancheng_2247485281-1.txt

两年前写过AI产业链:
从英伟达这类铲子，到制造铲子绕不开的台积电，再到亚马逊、微软这类云计算，最后是终端如GPT这类的应用。
这只是个轮廓，是AI行业内有大机会的企业，并不是全貌。这条产业链如果再继续延伸细分:
往上游是液冷、特种气体、电力设备等材料/设备;英伟达和台积电这类，属于芯片和制造，还有封装;往下延伸是变压器、电网等能源和物理基础设施;
再往下才是微软和亚马逊这类云计算巨头提供的算力服务和云;继续往下传导，还有数据清洗、数据库、RAG这类数据和中间件;最后才是应用层，应用层除了OpenAI这类模型，还有智能终端、机器人等硬件和垂直行业。
行业细分起来，上下游非常庞大，只不过两年前我只能抓主干，没有办法做到现在这么细化。不过，也幸好只抓主干，收益得以最大化。
要熟悉和精通一个行业的上下游，非常难，需要投入很多的精力和时间，能抓住几个最重要的绕不开的节点，就已经极好。
做企业的，在做投资时会比普通投资者有一定的优势，就是对企业的了解会更透彻，企业的商业模式、文化等等。
现在的美股，高位震荡时，鬼故事频出，和美债一样，时不时就要被质疑，这不是什么坏事。
其实不需要听那么多鬼故事，自己吓自己。投资最重要的是应对，而不是预测，目前的美股关注重点，应该聚焦在企业的盈利是否持续增长和可持续。
只要企业盈利仍在增长，且可持续性没有受到挑战，美股就仍然可以看好。
如果一家优质的科技巨头利润在增长，股价不涨，性价比越来越高，基本面没恶化，适合耐心去长期持有。
追涨杀跌本质上就是在追着钱跑，但人是追不上钱的，从来不是人赚钱，是钱在找寻人，钱在寻找它的主人。
看懂趋势，提前布局，耐心等待，钱自己就进入口袋了。赚钱挺简单的，也挺难的，耐心、勇气和资金，缺一不可。
人的认知，是无法超越自身经历的。看得再多，眼睛会了，但那都是别人的心得体会，等自己真实践起来，脑袋瓜还是不会，因为自己还没有真正理解和消化。
… …
今天跟我哥们聊天，聊了挺久的，拖到这会才写稿。
我们聊天的内容，能写的部分我整理个概要:
从微观层面去寻找目前国内的投资机会，主要集中在四个方向。
首先是大众消费这个板块，民生的生意其实是最好做的，属于刚需，如水电燃气粮食等，但被华润等国企央企入局垄断后，普通人能做的也不多，衣服和普通消费品极致内卷，主打都是性价比。
性价比卷到头，质量就会出问题，食品安全等很难得到有效保障。
大众消费要么往高端去做利润，要么往低端去卷规模、卷性价比，把供应链做到极致。
其次是养老板块，又称银发经济。
当然咱们的生育率低，少子化正在加速。而咱们的养老金是农村老人、村镇城市职工、体制内三轨制。
普通家庭的老人消费预期更保守，更倾向于储蓄，叠加养老金额的差异大，越没钱的老人就越倾向于储蓄，越有钱的老人越能帮扶子女，直至走出两条完全不同的路。
说白了，咱们的银发经济将是一个不成熟的市场，只有结构性的机会，也只有那些领着高额养老金的人群才有足够的消费能力，但他们又普遍不愿意去养老院。
结合欧洲、美国、日本和香港的经历来看，首先是这些地区都会提升保险和养老金的配置比例（25%+），其次是存在跨国/跨地区养老的机会，如香港外溢至深圳珠海等大湾区城市，日本、欧美的外溢至东南亚等。
然后是不良资产处置板块。
咱们的不良资产处置，市场潜力巨大，房地产债务是重头戏，后续地方政府债务也值得关注。
当然，不良资产处置这个市场将来会越来越大，风险和机会都很大，操作难度也大，要想玩得转，需要有过硬的资源、技术、关系。
最后是企业和个人出海。
这个讲过挺多次的，随着告别高增长，现在内卷压力越来越大，往外走是行之有效的渠道之一。
咱们人口占全球比重18%的情况下，产能占了全球的30%，消费占比还不到14%;
作为比对，美国人口占全球4%，产能占比约16%，消费占比30%;日本人口占比1.6%，产能占比约5%，消费占比约6.5%…
老美和日本现在的大型企业基本都是跨国公司，日本上市公司超4成的营收来自海外市场，前十大上市公司8成营收来自海外市场;美国头部上市公司的海外营收占比也普遍在50-60%;咱们目前上市公司的海外营收占比约17%…
目前咱们企业出海主要往东南亚和南亚、墨西哥。不仅要需要熟悉当地的法律法规和尊重当地的文化、信仰，还要应对发达国家的贸易摩擦，如溯源等。
个人出海，要么掌握语言和技能，出海谋生，要么资金出海参与全球优质资产的投资。
最后，我们聊了日本失去三十年这个话题，共同认为，真正要担心的不是日本化，而是拉美化。
中等收入陷阱本质上是制度陷阱，即杨小凯说的“后发劣势”，这种劣势源于“信念”，甚至很难用时间抹平。
总之，人口就是税源，年轻就是力量。在人口危机面前，其它问题都将居于次席，因为人口危机又将恶化其它问题。
… …

开学这段时间，三个上学的孩子融入都很不错。
他们一个班级就十几个学生，学校和老师也都很照顾他们的感受。
有时还是要感叹科技发展带来了很多学习的便捷性，老大小的时候，还只能和我开始学英语时一样，听BBC6分钟英语等英语音频，练习语感和发音。
到了老三，小时候就是一边玩一边学，多邻国app这类学习工具已经在国内上线（印象中是2020年初），可以在玩耍中学习和积累英语词句，还有数字积木等动画片可以看，属于一边享受一边学习，很有成就感。
科技发展带来的学习机会和渠道其实挺多的。现在有一些取消英语主课地位的声音，这是对底层最大的不公，但呼声最高的恰恰是底层，挺有意思的。
英语+任何一门技术，勇敢走出去，都能让你活得不错。
我们要发展好自身，而不是沉迷于宏大叙事。走向世界，再回望中国，而不是坐井观天。
不要像司马夹头那样，嘴上各种喊爱国口号，私底下偷税漏税，虚伪又丢人现眼。
爱是种情感，本应源于亲身经历和自身感受，不该停留在嘴上。
最近发现一本书，写得很不错，和我自身对孩子的教育理念和方式很契合，《正面管教》。
查了一下才知道，这是全球家庭教育和亲子关系领域的经典著作。书中尊重、理解、同理心，引导孩子解决问题和遵守规则等，和我平时对孩子采用的方式很相似。
非要挑这本书的缺陷，就是执行门槛高，对父母的情商和耐心是一大考验。
就这样吧。
