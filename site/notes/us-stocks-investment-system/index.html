玑哥美股投资体系：三账户配置、负成本打法与全生命周期资产规划

2026 年 5 月 24 日
玑哥美股美股投资体系资产配置宽基指数负成本持仓

完整梳理玑哥（金渐成）的美股投资体系——进取/稳健/防守三账户分工、科技七巨头的负成本打法、宽基指数 ETF 配置、杠铃策略下的创富与守富节奏、五大投资原则与不同资金量的实操建议。

读玑哥（金渐成）公众号的人，最常问的一句话是："你重仓的是哪几只美股？"

但翻完他这几年关于美股的所有文章之后，你会发现一个反直觉的事实：他最在意的从来不是哪只股票最赚钱，而是怎么把整套体系搭起来——一个能持续赚钱、能守住已有财富、能在任何市场环境下都不会被打趴下的完整体系。

这篇文章把玑哥美股投资体系完整梳理一遍：三账户分工、个股分类、负成本打法、杠铃策略、全球配置、五大原则，以及不同资金量该怎么落地。

一、玑哥美股投资体系的总纲：体系大于个股

整套体系围绕一个目标和一个方法论：

  • 目标：赚到钱 + 守住钱 + 持续增长；
  • 方法论：创富阶段 + 守富阶段 + 全生命周期规划。

绝大多数人只想要前半句"赚到钱"，玑哥反复强调：守住和持续，比赚到更难，也更重要。

二、三账户体系：让每一笔钱各司其职

玑哥美股投资体系最核心的一张图，是把全部资金分成三个互相配合的账户。

进取型账户（约占 25-30%）

特点：高风险高收益，主动管理。

持仓：

  • 美股七巨头：微软、苹果、英伟达、特斯拉、Meta、谷歌、亚马逊；
  • 其他关键科技股：台积电、博通。

选股标准：改变未来的科技龙头，具备长期护城河和增长潜力。

这是体系里赚钱的引擎。

稳健型账户（约占 15-20%）

特点：中等风险，被动 + 主动混合。

核心配置：

  • 宽基指数 ETF（占 60-70%）：纳指 100（QQQ）+ 标普 500（SPY / VOO）；
  • 个股（30-40%）：消费龙头（可口可乐等）+ 医药保健（联合健康、强生、礼来等）。

玑哥反复强调一句话：

普通人如果水平很一般，持有纳指 100 + 标普 500 这两个宽基指数 ETF 还是很好的。

宽基的好处是：分散、省事、费率低、长期跑赢大多数主动基金、不用天天看股价——这五条任何一条都足以让普通投资者受益终生。

防守型账户（约占 40-55%）

特点：最低风险，长期持有，作为整个组合的压舱石。

核心配置：

资产类别具体标的目的
股票可口可乐、强生、伯克希尔分红稳定
红利 ETFSCHD、VYM持续派息
债券美债 ETF、债券基金资本安全
现金美元存款、货币基金流动性
其他美元保险、不动产多元配置

这部分最值得放进玑哥美股投资体系核心位置的，是几只"不被未来改变"的公司：

  • 可口可乐（KO）——107 年历史，66 年不减息的红利贵族；
  • 伯克希尔（BRK）——巴菲特掌舵的保险 + 投资综合体，本身就是美股蓝筹股大集合；
  • 强生（JNJ）——医药健康全产业链，59 年连续增息，抗衰退能力极强；
  • 美债——3-4% 的收益率 + 极低风险；
  • SCHD / VYM——精选高质量分红股。

最有意思的是，进取型账户在震荡时受伤，防守型反而上涨 + 派息——形成完美互补。

三、个股分两类：改变未来的，与不被未来改变的

玑哥美股投资体系里有一个简单但深刻的个股分类：

类别代表属性买点
改变未来的科技龙头七巨头、台积电、博通高风险高收益、长期增长深调、黑天鹅后
不被未来改变的消费/避险股可口可乐、伯克希尔、强生低风险稳定收益、抗周期稳定积累、长期持有

这两类一前一后，对应的就是进取与防守两端的杠铃。

四、负成本持仓：玑哥美股投资体系里最精妙的打法

如果只挑一条玑哥美股最值得抄走的实操方法，就是负成本持仓。

概念

通过分红、派息、卖出部分获利，把成本不断降低，甚至降到零以下。

步骤

  1. 初始建仓——在低位大量买入；
  2. 高位分批减仓——股价涨到目标价位时分批卖出；
  3. 持续派息和分红——稳定现金流回收；
  4. 成本不断下降——最终可能达到零成本甚至负成本。

优势

  • 能拿得住——成本低就不怕波动；
  • 敢抄底——大跌时有现金流和心理空间；
  • 资金利用率高——卖出的钱可以投到其他机会；
  • 让利润继续跑——核心底仓始终保留。

英伟达就是典型案例

  • 在 AI 热潮真正爆发前，低位大量建仓；
  • 当股价涨到 190 / 195 / 200 等关键价位时，按计划分批卖出；
  • 每次卖出都落袋为安，同时保留足够底仓让利润继续跑；
  • 最终成本不断下降，进入"零成本甚至负成本"的状态。

做低成本 / 负成本，让利润在里面继续跑，往往能拿得住、拿更久；遇到大跌还敢抄底，没有任何心理负担；还能提升资金的利用率。

五、市场节奏：什么时候加仓，什么时候减仓

玑哥对美股节奏的判断浓缩成一段话：

美股都有规律，涨多了就调整，调整结束了就继续涨。最重要的是大跌的时候要有勇气爆买，涨到预期了再开始逐步减仓，不要拿不住一早就开始卖。

可执行的对照表：

市场状态操作原因
大幅下跌（-20%+）爆买，用足杠杆筹码便宜，风险已释放
温和调整（-5～-10%）常规加仓布局中枢
持续上涨分批减仓到目标价落袋为安
极度疯狂（单月 +25%）大幅减仓风险超大，保护利润

判断"涨到预期了"没有固定数字，但有四个观察点：市场情绪 + 估值指标 + 技术面信号 + 宏观流动性变化。原则是——不要一早就卖，也不要从不卖。

六、杠铃策略：玑哥美股投资体系的生命周期

用科技股做"印钞机"，不断赚到收益，并转向配置能守住财富的资产品类。

这就是杠铃策略，也是整个玑哥美股投资体系的灵魂——用一端创富，用另一端守富，再让两端互相滚大。

第一阶段：创富（30-45 岁）

  • 进取型占比 60-70%；
  • 重仓科技股 + 敢于加杠杆 + 底部爆买；
  • 大跌时敢 all in，上涨时不急于减仓；
  • 财富目标：100 万 → 1000 万这一跃。

第二阶段：守富（45-60 岁）

  • 进取型降至 25-30%；
  • 防守型升至 40-55%；
  • 科技股高位套现 → 转入可口可乐、伯克希尔等；
  • 新增全球不动产、美元保险。

第三阶段：享受（60+ 岁）

  • 防守 50-60%、稳健 20-30%、进取 10-20%；
  • 收入主要来自派息 + 分红 + 不动产租金 + 保险分红；
  • 系统自动运行，不需要每天看盘。

玑哥本人的现状是：进取型和防守型已经持平——说明他正处在从创富向守富的转型阶段。

七、全球配置：外面赚钱，里面花

对中高净值群体，玑哥反复强调一句很有画面感的话：

最好的还是"外面赚钱里面花"——在通胀的地方赚钱，在通缩的地方花钱。

全球配置的三大支柱：

1. 美股

进取 + 稳健 + 防守三账户，已经覆盖核心增长。

2. 不动产

  • 美国农业用地——两块已出租，持续租金；
  • 新西兰农场——大型优质农场（200 万 ㎡+），收益率 13-14%，发达国家中名列前茅；
  • 澳洲——筹划中，完成不动产全球闭环。

不动产的四个优势：实物资产不会归零 + 产生租金 + 抵抗通胀 + 可传承给后代。

3. 保险与数字资产

  • 美元类保险——对冲本币贬值，可继承；
  • 比特币——大约占资产 1/3，2022 年底做空避险、2023 年初转做多；
  • 其他：港股（腾讯等）、日股、英股、印度等。

参考的总资产配比：

资产类别占比角色
美股50-60%核心增长
全球不动产20-30%抗通胀、稳定
数字资产5-10%高弹性
保险5-10%对冲、继承
现金5-10%流动性、机会
其他5-10%灵活调整

八、五大投资原则：玑哥美股投资体系的心法层

玑哥教女儿投资时强调的五条原则，也是整套体系的根基。

1. 专业性是基础

进阶到所处行业头部的 5%，才有机会始终呆在牌桌上。不然都是靠运气赚钱。

2. 耐心、勇气、专注

  • 耐心——大机会一定要拿住；
  • 勇气——大跌敢爆买，涨到预期敢减仓；
  • 专注——啥都想要就啥也得不到。

3. 安全边际是生存线

  • 100 万拿 10 万投——心态平和；
  • 100 万全梭哈再加杠杆——赌徒。

4. 知足、知不足、知所求

知道自己不知道什么，并清楚自己到底想要什么的人，能走得很远。

5. 情绪管理

发脾气谁都会；控制情绪，不乱发脾气，才是真本事。

九、不同资金量怎么落地玑哥美股投资体系

理论再好，要回到自己的账户。这里是按资金量拆出来的可操作配置：

资金 < 50 万美元

七巨头 70% + 台积电 10% + 宽基指数 20%

理由是不够分散到三账户，先集中在最确定的品种，用分红和派息逐步增加防守资产。

资金 50-500 万美元

进取型 30%（七巨头 + 台积电 + 博通）
稳健型 20%（宽基指数 + 消费股）
防守型 50%（可口可乐 + 伯克希尔 + 美债 + 派息 ETF）

进取型产生的收益逐步转入防守型，定期做资产再平衡。

资金 > 500 万美元

美股 50%
不动产 25%
保险 + 现金 15%
其他灵活 10%

可考虑全球不动产（美国、新西兰、澳洲）+ 美元保险 + 私募 / 对冲基金 + 家族基金。

十、风险管理：活得够久才是真赢

玑哥关于风险的判断只有一句：

投资首先是保值，其次才是增值。

四类需要主动管理的风险：

  1. 美联储政策变化——监控利率走向，保留足够现金；
  2. 科技股集中风险——七巨头之外还有台积电、博通，加上宽基指数对冲；
  3. 地缘政治风险——全球配置 + 不动产多国布置 + 保险对冲；
  4. 黑天鹅事件——保留 10-20% 现金 + 防守型 40-50% + 美债避险，永远不要满仓。

底层逻辑只有一句："防守是为了更持久、更好地进攻。上战场穿盔甲会比没有防护更好。"

十一、五句话记住玑哥美股投资体系

如果只能带走五句话：

  1. 体系大于个股——赚钱、守钱、持续增长三件事一起做。
  2. 三账户分工：进取、稳健、防守，缺一不可。
  3. 负成本持仓：用分红、派息和分批减仓把成本降到零以下。
  4. 大跌爆买，涨到预期分批减仓，不要一早就卖。
  5. 保值优先于增值——活得够久才是真赢。

结语：体系是给未来十年的自己准备的

玑哥在《有所爱，无所畏》里写过一段被很多人转引的话：

开始越来越喜欢安静和独处。找个景色宜人处安静地品一杯茶，发呆、种花草、养鱼……能做自己喜欢的事，不需要迎合这个世界的熙熙攘攘，无疑是件幸福的事。

玑哥美股投资体系最终要回答的，其实不是"今年赚多少"，而是——

十年后，你能不能不再为钱焦虑，能不能把更多时间留给自己真正喜欢的事？

体系存在的意义，就是让那个答案从"看运气"变成"看安排"。
